# MadsChinese

MadsChinese is a desktop Chinese learning application focused on fast dictionary lookup and reading practice.

Paste or type Chinese text into a workspace and hover over words to instantly view definitions, pinyin, and translations. The application uses local CEDICT data and runs entirely on your machine, providing a fast and offline-friendly learning experience.

Built with Vite, React, TypeScript, Tailwind CSS, and Tauri.

## Features

* Chinese text workspace
* Paste or type Chinese text
* Instant hover dictionary lookup
* Local offline dictionary data
* Chinese-English word definitions
* Tone-colored pinyin display
* Multi-character word matching
* Highlighted dictionary matches
